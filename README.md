# ZGNBCARD使用说明
🔹 抽牌：点击卡牌本身或【抽牌】按钮，卡牌 3D 翻转随机显示语录，重复点击可换新；

🔹 触控解锁：点【🚫】按钮变【✋】，卡牌可点击抽牌，复点恢复锁定（仅按钮可抽）；

🔹 声音开关：点【🔊/🔇】切换抽牌是否自动播放对应音频（默认开）；

🔹 播放当前：点【▶️】随时播放当前卡牌语录的音频（不受声音开关影响）；

🔹 重置：点击【重置】，卡牌翻回背面，恢复初始 “点击抽取语录卡牌” 状态；

🔹 验牌：点【验牌】弹出语录列表，顶部「序号 / 查看 / 播放 / 语录」表头会吸顶，滚动时一直看得到列名；点左侧【🔍】把该语录翻到卡牌并关列表，点【▶️】播放对应音频；

🔹 退出列表：右上角【×】、列表底部【关闭】、点列表外面，三种方式都能退出，手机上不用再滚到底部找关闭；

🔹 手机返回键：列表或说明打开时按返回键，会先关掉这一层，再按一次才离开页面；

🔹 小提示：操作提示悬浮 2 秒自动消失，页面适配手机等小屏设备。
